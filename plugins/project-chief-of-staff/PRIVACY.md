# Privacy

Project Chief of Staff runs on your own computer, inside Claude Code. Its author receives no data from it.

- **What it reads:** the folder you run it in. Files elsewhere are read only when you type their paths, and copied in
  only item by item with your approval. Originals are never moved or changed.
- **What it stores:** the project it builds, and any files you chose to import, all inside that folder and under your
  control. Delete the folder to remove everything.
- **What it sends:** nothing. The plugin and the tools it generates make no network requests and have no telemetry or
  analytics. The one optional step that downloads anything is installing the Playwright CLI from the npm registry, and
  it runs only if you choose it.
- **Claude itself:** your conversations with Claude Code are handled by Anthropic under Anthropic's own terms and
  privacy policy. This plugin doesn't change that.
